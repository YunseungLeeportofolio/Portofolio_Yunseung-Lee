# 정치인 유튜브 선거 캠페인 콘텐츠 코딩 데이터

「정치인 유튜브 선거 캠페인 콘텐츠의 소구와 이용자 참여」(『사회과학연구』 32(4), 2025)의 분석 데이터입니다. 제22대 총선 부산 지역 더불어민주당 · 국민의힘 후보 35명이 2024.02.26 – 04.10에 게시한 유튜브 롱폼 영상 376건을 영상 단위로 코딩했습니다. 이 저장소에는 그중 46건만 예시로 올렸으며, 연구진과 함께 구축한 만큼 전체 데이터는 공개하지 않습니다.

## 변수

| 변수 | 설명 |
|:--|:--|
| `Title` | 영상 제목 |
| `Party` | 후보 소속 정당 (0 = 더불어민주당, 1 = 국민의힘) |
| `Link` | 영상 주소 |
| `ViewCount` · `Comment` · `Like` | 수집 시점의 조회수 · 댓글 수 · 좋아요 수 |
| `V1` – `V13` | 영상 재생 시간에서 각 소구 유목이 차지한 비율 (%, 행 합계 100) |
| `Total_time` | 영상 길이 (초) |
