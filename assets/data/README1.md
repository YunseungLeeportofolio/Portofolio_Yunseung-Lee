# 간호법 언론 · 여론 분석 공개 데이터

「2023 간호법 제정에 관한 국내 언론보도와 국민여론 분석」(대한간호협회 의뢰 연구, 2023)에 쓰인 데이터 가운데 일부를 예시로 공개합니다. 언론 보도 데이터는 기사의 저작권이 각 언론사에 있고, 유튜브 댓글과 커뮤니티 게시글은 이용자가 작성한 글이어서 작성자의 권리와 개인정보 보호를 위해 전체 데이터는 공개하지 않습니다. 유튜브 댓글과 커뮤니티 게시글은 간호법 재표결이 국회에서 부결된 2023년 5월 30일 전후의 자료입니다.

| 파일 | 내용 | 건수 | 기간 |
|:--|:--|--:|:--|
| `medical_all.csv` | 5개 일간지의 간호법 관련 기사 (빅카인즈 수집) | 24건 | 2023.05.30 – 05.31 |
| `YTC.csv` | 대한간호협회 유튜브 채널 댓글과 감성 · 비시민성 분석 결과 | 44건 | 2023.05.31 |
| `sentiment_analysis_result_fm.csv` | 온라인 커뮤니티(에펨코리아) 게시글 제목과 감성 · 비시민성 분석 결과 | 20건 | 2023.05.28 – 05.31 |

<sub>전체 분석에는 빅카인즈 보도(2021.01 – 2023.05), YTN 기사 · 방송 스크립트 605건, 온라인 커뮤니티 4곳 게시글, 협회 유튜브 댓글 4,336개가 쓰였습니다. 자세한 내용은 [프로젝트 페이지](../../projects/nursing-law.md)에 정리했습니다.</sub>

## 1. `medical_all.csv` · 언론 보도

한국언론진흥재단 빅카인즈에서 내려받은 기사 데이터입니다. 조선일보 · 중앙일보 · 동아일보 · 한겨레 · 경향신문의 기사가 들어 있습니다.

| 변수 | 설명 |
|:--|:--|
| `뉴스 식별자` | 빅카인즈 기사 고유 번호 |
| `일자` | 보도일 (YYYYMMDD) |
| `언론사` | 기사를 낸 언론사 |
| `기고자` | 기사를 쓴 기자 |
| `제목` | 기사 제목 |
| `통합 분류1` – `통합 분류3` | 빅카인즈 주제 분류 (예: `정치>국회_정당`, `사회>의료_건강`) |
| `사건/사고 분류1` – `사건/사고 분류3` | 빅카인즈 사건 · 사고 분류 (예: `사회>사회갈등>시위`) |
| `인물` · `위치` · `기관` | 기사에 등장한 인물 · 지명 · 기관 이름 |
| `키워드` | 빅카인즈가 형태소 분석으로 뽑은 키워드 |
| `특성추출(가중치순 상위 50개)` | 가중치가 높은 순서로 뽑은 핵심어 |
| `본문` | 기사 본문 앞부분 200자 (빅카인즈가 제공하는 범위) |
| `URL` | 기사 원문 주소 |
| `분석제외 여부` | 빅카인즈의 분석 제외 표시 (이 파일에서는 모두 해당 없음) |

## 2. `YTC.csv` · 대한간호협회 유튜브 댓글

| 변수 | 설명 |
|:--|:--|
| `날짜` | 댓글 작성일 |
| `댓글` | 댓글 원문 (작성자 정보는 포함하지 않음) |
| `sentiments` | 딥러닝 감성 분류 결과 · `LABEL_1` = 긍정, `LABEL_0` = 부정 |
| `scores` | 긍정일 확률 (0 – 1) · 0.5 이상이면 `LABEL_1` |
| `incivility` | 비시민성 분류 결과 · `None` = 해당 없음, 그 밖에는 범주 이름 (예: `단순 악플`) |
| `incivility_scores` | 모델이 예측한 비시민성 범주의 확률 (0 – 1) |

## 3. `sentiment_analysis_result_fm.csv` · 온라인 커뮤니티 게시글

| 변수 | 설명 |
|:--|:--|
| `post` | 게시글 제목 (말머리 포함, 예: `[정치/시사]`) |
| `date` | 게시글 작성일 |
| `sentiments` | 딥러닝 감성 분류 결과 · `LABEL_1` = 긍정, `LABEL_0` = 부정 |
| `scores` | 긍정일 확률 (0 – 1) · 0.5 이상이면 `LABEL_1` |
| `incivility` | 비시민성 분류 결과 · `None` = 해당 없음, 그 밖에는 범주 이름 (예: `단순 악플`) |
| `incivility_scores` | 모델이 예측한 비시민성 범주의 확률 (0 – 1) |

## 읽을 때 참고할 점

- **감성 점수의 기준** — `scores`는 긍정일 확률이라 1에 가까울수록 긍정, 0에 가까울수록 부정입니다. 이 예시 데이터의 평균은 협회 유튜브 댓글 0.80, 커뮤니티 게시글 0.38로, 전체 분석 결과(0.7 대 0.3)와 같은 방향입니다.
- **협회 유튜브 댓글의 해석** — 협회 채널을 찾아온 이용자의 반응이라 긍정 비율이 높게 나옵니다. 그래서 전체 분석에서는 일반 여론이 아니라 비교 자료로만 사용했습니다.
- **자동 분류의 한계** — 감성과 비시민성은 모델이 자동으로 분류한 결과입니다. 전체 분석에서는 분류 결과를 원문과 대조해 해석했습니다.
