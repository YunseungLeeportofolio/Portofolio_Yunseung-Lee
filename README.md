> - 기간 : 20XX.XX - 20XX.XX (개인 연구)
> - 데이터 : 보수·진보 YouTube 채널 영상 N개, 댓글 N만 건
> - 파이프라인 : 데이터 수집 → 전처리 → 무례함 탐지(KcELECTRA) → 감정 분류(KOTE·TODE) → 토픽 모델링(STM·BERTopic) → 네트워크 분석

> **핵심 성과**

> - 선택적 노출·교차 노출 지표로 채널 성향별 댓글 반응 차이를 비교
> - (발견한 인사이트 한 줄 — 예: 교차 노출 댓글의 무례함 비율이 N%p 높음)
